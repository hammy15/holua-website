🎓 5-Step Analysis Methodology

Based on Solvaix multi-agent and Anthropic PLAN→SPLIT→BUILD principles

1
PLAN
Define what the deal depends on. Identify constraints (zoning, location, capital) before any calculations begin.
2
SPLIT
Decompose into independent analyses. Each agent (Yield, Margin, Risk, Timing, Flip) works in parallel without knowing what others found.
3
BUILD
Synthesize agent outputs. Weight by importance (Margin 35%, Yield 20%, Risk 20%, Flip 15%, Timing 10%).
4
CLASH
Detect conflicts between agents. High yield + high risk? Good margin + slow timing? Surface these for human decision.
5
DECIDE
Generate actionable verdict: STRONG BUY / BUY / MAYBE / PASS. Include specific next action and recommended strategy.
